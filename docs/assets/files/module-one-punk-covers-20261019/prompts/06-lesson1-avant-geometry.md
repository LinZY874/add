# 黑白灰先锋几何 cover prompt

You are a top-tier cover art director, avant-garde editorial designer, typography designer, and image-generation prompt director.

Create one single WeChat Service Account article cover, aspect ratio 2.35:1, target 1410×600, single final image. Use case: experimental Chinese editorial cover. Language: Chinese with restrained English auxiliary text.

## Input and content understanding

- Title/topic: AI到底是什么
- A-layer main visual title: AI到底是什么
- B-layer complete title: AI到底是什么
- C-layer auxiliary text: GENERATE / RECEIVE / ACT
- Short context: 文章以十个概念拆解 AI：模型和 Token 如何生成，Prompt、Context、RAG 如何提供信息，Tool、Skill、Agent 如何把回答推进为行动。
- Audience: 希望看懂 AI 系统结构的普通读者与设计敏感型职场人。
- Mood: 先锋、冷静、动态、有秩序的未知感。
- Visual metaphor: 三个几何场域从离散点阵，经上下文圆环，进入向前的透视路径，表达生成、接收、行动三阶段。
- Banned elements: 机器人、机械脑、芯片、具象插画、固定左文右图模板、书法体、卡通字体、关键字被遮挡、乱码。

## Style application and composition

Use black-white-gray avant-garde poster language with controlled asymmetry, extreme negative space, and modernist tension. The exact title “AI到底是什么” must remain clear, accurate, and dominant, but use a varied composition: “AI” large near the upper-left axis, “到底” on a strong horizontal baseline through the center, and “是什么” completing the title toward the lower-right without turning into a fixed left-title/right-graphic template. The reading order must remain obvious.

Integrate exactly four geometric motifs with the title: a sparse dot matrix dissolving into the “AI” negative space; one cut circular ring intersecting the baseline around “到底” without covering strokes; a narrow perspective rectangle field passing behind “是什么”; and one thin waveform/path line tying the three zones together. Use black, white, mid-gray, one translucent gray plane, and a single tiny signal-orange node at the end of the path.

Place “GENERATE / RECEIVE / ACT” once as small condensed sans-serif auxiliary text rotated 90 degrees along an outer edge, supporting structure without competing with the Chinese title. No other text. Add subtle paper grain, faint embossing, thin grid traces, and very small print misregistration only where useful.

Reading path: AI → 到底 → 是什么, then the dot-to-ring-to-path geometry, then the English auxiliary. Maintain strong social-thumbnail legibility.

Avoid fixed left-title/right-circle layouts, random geometry, geometry covering key strokes, calligraphy, handwriting, cute or cartoon type, excessive fragmentation, colorful poster treatment, literal robot illustration, decorative noise, PPT/course cover, e-commerce feel, gibberish, contact sheets, or alternatives.

Generate only one final image.
