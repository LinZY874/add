# 拆解视频片段的视觉与转场手法

从视频或片段描述中提炼可复用的视觉与转场手法，用简短的名称和一句大白话讲清画面如何变化。

- 分类：提示词
- 收藏日期：2026-11-05
- 标签：视频拆解、转场、镜头语言
- 主题：视频创作

## 提示词

```text
请分析下面的片段，找出其中使用的视觉表现或转场手法。每种手法给出一个简短的名称，再用一句大白话说明它是怎么做的。

名称要概括手法本身，换一个场景或道具也能用。有常见叫法就用常见叫法。如果没有固定术语，就给出一个直观的描述性名称。解释要让没看过原片的人也能想象出画面是怎么变化的。

输出示例

1. 引导物｜用一个移动的视觉焦点吸引观众的视线，再带着视线进入下一个场景。
2. 嵌套拉远｜镜头拉远后，原本占满画面的上一幕缩成下一幕的一部分。

待分析片段

[在这里粘贴片段描述或附上视频]
```
