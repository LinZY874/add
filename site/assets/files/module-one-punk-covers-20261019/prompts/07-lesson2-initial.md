# 立体纸雕概念海报 cover prompt

你是顶级封面艺术总监、编辑视觉设计师与中文字体设计师。创作一张完整的微信服务号文章封面。风格只能是「立体纸雕概念海报 / layered-paper-cut-concept-poster」，所有图文都以真实纸层空间构建。

## Input
- Title/topic：AI 工具选择指南
- Title hierarchy：A层和B层合为完整主标题「AI 工具选择指南」，只出现一次，分两行排版：第一行「AI 工具」；第二行「选择指南」。
- C层 / 副标题（逐字准确）：看懂产品差别，找到合适工具
- Platform：微信服务号文章封面。
- Aspect ratio：2.35:1 横向。
- Output dimensions：2256×960 px，原生宽幅构图。
- Output mode：单张独立封面，此次只生成这一张。
- Language：简体中文，保留AI拉丁字母。
- Use case：ads-marketing / editorial article cover。
- Short context summary：认识AI产品差别、费用和任务场景，按实际任务试用比较，选出合适的个人工具清单。
- Visual subject / metaphor：一张展开的立体纸雕地图，三条层叠纸路径中仅一条低饱和蓝色路径穿过切开的地形抵达精确嵌合的圆形终点。所有路径属于同一张折叠地图，不画多个分散物件。强调从选择到匹配的空间关系。
- Audience：学习AI应用的中文读者。
- Mood：理性、温暖、克制、精致。
- Banned elements：机器人、电脑屏幕、品牌标识、虚构小字、课程角标、日期、刊号、无关装饰。

## Content Understanding
第一眼读懂完整标题，第二眼读懂纸雕中一个明确的关系。只使用上述标题、副标题和内容摘要指导设计，不加入正文文字。

## Cover Objective
完成可直接作为文章封面的编辑级艺术作品。主副标题全部保留，清晰且无错字，所有标点准确。副标题不可过小。不是课程PPT模板，不要卡片式信息框。

## Style Application
真实厚纸经过精密切割、叠放、折叠和镂空后形成的艺术装置，由摄影棚柔光拍摄。真实可见的切边厚度、微细纤维、合理折痕、少量翘边和自然接触阴影。用有意义的4至6层纸建立空间，不机械堆层。只使用一个视觉隐喻。标题与纸雕共享材质、光线和空间，禁止平面插画加纸纹滤镜。

## Composition
完整横向2.35:1构图；宽裕奶油白留白，四边至少7%安全距离。左侧约56%是两行主标题和副标题所在的纸层平台，右侧约38%是一个主纸雕结构，二者由同一张纸层的连续折面连接，不能像左右拼贴。标题区域不得被图形遮挡。
主视觉：一张展开的立体纸雕地图，三条层叠纸路径中仅一条低饱和蓝色路径穿过切开的地形抵达精确嵌合的圆形终点。所有路径属于同一张折叠地图，不画多个分散物件。强调从选择到匹配的空间关系。
从左边标题到右边纸雕再到副标题，阅读路径清楚。整体纸雕略带浅俯视，字面接近正视保证阅读。背景纸延伸至整个画面，不加外框或样机环境，保留大量干净呼吸空间。

## Image-Text Relationship
主标题是深色厚纸切出的精准字形，轻微抬升并嵌入前景的奶油纸台面；投影细腻且浅，不做厚重挤出3D字。纸台面的右边自然折入主视觉装置，因此图文同处一个真实纸构场景。副标题采用深色油墨直接印在同一纸层上，避免悬浮文字。只出现主标题和副标题，不添加任何英文装饰字或课程编号。

## Typography
使用编辑级中文现代黑体，主标题粗体，字形端正，适当字距，两行整齐左对齐。第一行「AI 工具」；第二行「选择指南」。完整主标题合读必须是「AI 工具选择指南」。主标题占整体高度约36%，足够醒目。
副标题中等字重、清晰高对比，与标题留出充足呼吸距离；准确文字为「看懂产品差别，找到合适工具」。需要时按语义分成两行，但不能删字、换字或增加标点。主副标题不能相互遮挡。小屏缩略仍容易辨识。

## Color, Material, and Texture
整套视觉以暖奶油白未涂布高级棉纸作背景，柔和左上方摄影棚光线，投影统一朝右下，阴影自然透明。当前封面配色：深海军蓝主标题，灰蓝和雾蓝纸层，一条克制的陶土橙路径强调。有限配色，哑光可触摸纸张，不要金属、塑料、泡沫、亮面或数字渐变。主标题深色与浅色底形成明显对比。

## Negative Constraints
禁止多个主体、素材堆砌、儿童手工感、扁平剪纸边框、科技霓虹、硬黑阴影、廉价CG、花哨背景、通用PPT、电商风、密集信息、错字、缺字、乱码、裁切文字、重复标题、额外文案、拼图、网格、联系表。不能生成后裁切、拉伸、补边来凑比例。

## Final Standard
只生成这一张最终成图，原生2.35:1，精确2256×960。真实纸层，一个准确隐喻，清晰完整的主标题和副标题，图文共享空间，柔和统一光影，克制配色和高级留白。
